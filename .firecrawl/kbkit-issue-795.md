Issue body actions

The `KeyboardInputViewController`'s `openURL` function uses a selector-based way of opening URLs, that has stopped working in iOS 18.

The function currently uses the `openURL:` selector, which in iOS 18 gives you the following system log:

```
BUG IN CLIENT OF UIKIT: The caller of UIApplication.openURL(_:) needs to migrate to the non-deprecated UIApplication.open(_:options:completionHandler:). Force returning false (NO).
```

Trying to use `openURL:options:completionHandler:` doesn't seem to work either, which means that there is currently no way to handle the `.url` keyboard action.

To work around this, KeyboardKit 8.8.6 will render the `.url` action as a SwiftUI `Link` view, instead of a custom view with the full range of gestures.

If you need to work around this problem when using earlier versions of KeyboardKit, use regular SwiftUI `Link` views and customize the `SystemKeyboard/KeyboardView` button for `.url` to use a `Link` view.
